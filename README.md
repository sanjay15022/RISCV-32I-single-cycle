# RISC-V 32-bit CPU

A 32-bit RISC-V processor designed and implemented from scratch using Verilog HDL.

This project focuses on understanding computer architecture and processor design through hardware implementation. It involves building the CPU datapath, instruction decoding, control logic, ALU, register file, program counter, and memory interface.

The processor executes RISC-V machine-code instructions and is tested using custom programs implementing algorithms such as Fibonacci sequence generation, Merge Sort, Binary Search, and the Sieve of Eratosthenes.

The project aims to explore how software instructions are translated into hardware operations, how a processor handles arithmetic, memory access and control flow, and how individual hardware modules work together to execute programs.

**Built using Verilog HDL and simulated using Icarus Verilog.**
